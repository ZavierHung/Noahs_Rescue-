# 从学生视角迭代 Noah’s Rescue

日期：2026-10-30。主分支基线：`main@c32f6d3`，已推送；后续开发：`feature/student-learning-iterations`。本轮限定两次反馈迭代，不把修改中的版本直接替换主分支。

## 体验判断：有教育设计潜力，但还不能宣称教学有效

本次使用独立浏览器、临时存档及程序玩家，以第一次接触游戏的学生视角检查操作和表达。**没有招募真实学生，没有测量学习增益，也没有调用付费 LLM。**“趣味性”判断是设计审查，不是学生满意度数据。

值得保留的创新是组合方式：六边形求生、全员共享外部性、可追溯行为日志、带硬性容量约束的 AI 审议、根据申辩重新检索跨学科材料。它让公共物品、机会成本、生态约束和程序公平围绕同一场经历展开，不声称这些机制本身是首创。

基线的问题：

1. 主屏大面积世界滑条容易让学生把主持调分误认为正常行动，行动面板不够突出。
2. 卡图精致，但部分旧卡面文案与实现不一致，另一个长说明不足以消除困惑。
3. 邀约几乎总是有利，机器人频繁接受；多次点击并不自动等于有趣的决策。
4. 仅用登船/落选表达胜负，容易暗示“没上船就是坏学生”。绝对捐赠量也受出生地和机会影响。
5. 学术依据藏在折叠长段落里，难以联系自己刚做的行为。

## 方法与可复现记录

每批 20 局、6 人、种子 1–20，共 120 人次。平衡比较采用相同 `mixed` 策略：两名慷慨、两名均衡、两名谨慎机器人按种子分配；旗点及行动顺序固定。机器人不偷看未来随机数，不强制结果；使用真实规则和本地终判。

```bash
node scripts/evaluate-learning.mjs --matches 20 --output /tmp/noah-baseline-20.json
node scripts/evaluate-learning.mjs --learning --matches 20 --output /tmp/noah-learning-20.json
npm run test:simulation -- 20 --learning
```

前两条评估回合规则到离线登船；第三条另测完整服务、互评、申辩和终判，使用 `balanced` 策略，不混合计算。JSON 保留逐局、逐席位、极端世界值、操作数及局限。20 局仅提供初步设计信号，不是精确平衡证明。

## 迭代 1：选择有代价，结局不只奖励上船

基于 [基线 20 局](iterations/baseline-20.json) 后实施：

- UI：紧凑世界仪表，手动滑条折叠到“主持／实验模式”，保留理由和确认；行动面板前置，当前玩家与只读查看区分。
- 采矿无人机：部署经济 +1；普通采集无自动奖励；可增产同类资源 1 份，每次环境 −1。设备不叠加，将每次环境成本绑定获益。
- 共享补给：公开随机人数 +1 份，当前库存少者先选，每人 1 份，同量按座位，余下弃置。仍有社会 +2、经济 +1、环境 −2 的代价。
- 生态崩坏：低环境下采集后休养完整一轮；第 r 轮采、第 r+1 轮禁采、第 r+2 轮恢复，历史全体共享。简化再生机制，**不表示金属、电力会自然长出**。
- 美术：依照原蒸汽朋克、羊皮纸、蓝金／棕金风格重绘以上 3 张卡，卡面改为新效果。保留旧图，保持比例；见 [美术记录](iterations/ART_REVISION.md)。
- 玩家互评：包括未存活者在内的所有玩家轮流评分 1–5、评论、选择最多 3 条真实事件；可不评或明确跳过。全部完成后才初审。评价是观点，不直接累加登船分；第一份互评提交后锁定撤回，避免看评价再改历史。
- 多层结果：共同生存目标、公共运力目标、生态净影响，以及个人捐赠／合作／修复事实，最后单独展示登船名单。主持调分干扰生态归因时标为不可评，不算玩家贡献；这些不是学生道德分或学习成绩。
- 教育传递：默认展示一个学术概念、一条行为线索及反思问题。长文献仍可展开。人设→本地 RAG→初判→逐人申辩→终判核心不变；互评独立进入上下文，不改变生存和容量硬限制。

新网页对局默认学习版本；无 `learningMode` 的旧存档继续旧规则，不在中途变更语义。

[迭代 1 明细](iterations/iteration-1-20.json)。按对局正态近似的 95% 区间：存活约 73.5%–86.5%，登船约 46.4%–55.3%。不能把单次 80% 当作真实玩家的保证。

持续极端世界值减少；**总点击量与捐赠差异未改善，位置差异仍明显。**不继续单纯调伤势阈值追目标。额外 20 局只轮换旗点：原 P1 登船 90%→40%，原 P3 换到 P4 旗后 20%→75%。地图路线长度和周边资源不等价，不能用随机奖励假装已平衡。

完整服务另跑 20 局 `balanced`：60 份评分评论、60 次跳过、111 次申辩、151 次离线模型接口契约检查，真实 LLM 请求 0。存活 92.5%、登船 43.33%，策略敏感性很大。见 [服务闭环记录](iterations/iteration-1-service-20.json)，不与上表混算。

测试覆盖旧规则兼容、非法互评无写入、重复提交、重启留档、写盘失败回滚、评价注入、生存与容量硬约束、浏览器完整互评流程和手机布局。卡图另校验尺寸和比例。

## 迭代 2：下一批反馈

计划每局仅 3 次公共随机二选一，让收益、环境和公共福祉有取舍。独立随机源不直接扰动原抽牌／洪水骰子，不给随机当选的决策者自动个人加分。完成后再跑同样 20 局并记录。

## 仍需真实学生验证

建议教师带领 6 人试玩，前后用同一道情景题检查外部性、公平与机会成本的解释能力，记录误读、等待时间、互评压力与落选情绪。问“如果换一个出生位置，理由还成立吗”，不只问“哪个按钮加分”。真实 LLM 的引用质量与学生概念迁移仍需单独评估，本次不宣称已完成。
