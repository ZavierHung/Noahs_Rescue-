## 来源特点与权威边界

使用原研究出版方、学术机构、政府出版平台、官方讲演档案及有明确出处的开放教材版本，未以营销文章代替学术来源。出版年为 1998—2023，原文全部英文。新增教材改善了基础概念覆盖，但仍偏向英语大学教学与气候治理研究，缺少中文原创教材、本土研究和地方知识，不是系统综述或全球代表性样本。

曼昆与 Perman 提供成熟教材中的常见机制；CORE、Lyryx、BCcampus、Rebus 等提供不同组织形式的本科开放教学框架；Bowles / Halliday 为研究型中级教材，Commons 为专业课程教材，Taylor 则单列为课程指南。**教材是教学综合，论文是具体研究，规范伦理是理由与价值框架，不能把它们的权威程度或证据性质混为一谈。**本库没有依据目录或书名编写未读章节的观点，且明确标出讲义、样章、校样和网页版本。

IPCC 的优势是多研究综合与明确置信度，不意味着结论可以直接换算为游戏阈值。Science Advances 与 PNAS 论文均经同行评审，但方法不同：前者综合地球系统指标，后者主要基于专家征询、工作坊与文献综述，不能统称为已验证的干预实验。

NBER 条目明确为工作论文。三篇讲演的学术影响力不等于每项规范判断都是科学共识。Dasgupta 是委托独立综合评论，Aldrich 等是指南章节，均不冒充随机试验。获奖、顶刊和政府平台都不能替代论证。

「种子救生」「方舟席位」「世界分数」是游戏机制，文献没有检验这些机制，更没有提供人命价值排序。游戏中活下来或获准登船不代表现实道德高下。

## 上帝如何使用资料

核心链条不变：状态与全程日志 → 随机完整人设 → 本地检索 → 初判 → 逐人申辩并重新检索 → 终判 → 生存、容量及证据校验 → JSON 留档。

新增 12 份材料附有 68 个中文概念标签，用于定位外部性、程序公平、风险共担等具体问题；**68 是标签数量，不是 68 篇文献或 68 项独立研究**。`workId` 标识作品，`edition` 标识版本，`originalFormat` 区分 PDF、网页与仅外链，`supportingUrls` 指向所读章节及版次依据。教材与研究材料进入同一检索流程，不替换完整人设，也不增加上帝的操作权限。

1. 查询包含共享分数、捐赠、玩家处境、近期事件摘要和全部陈述；完整日志另行提供模型。当前申辩为重点，终判综合全部陈述，不复用初判证据。
2. 中文关键词与中英文术语映射主导相关性，Hash-256 向量作弱辅助。人设适度影响排序，兼顾三领域与不同视角。相关材料充足且位置允许时，同时保留教学基础与研究背景；不牺牲前两条相关命中、不把课程指南算作研究、不强塞无关资料。无关键词匹配时不返回纯哈希碰撞结果；这不是真正的语义嵌入模型。
3. 模型收到中文结论、局限、出处及完整人设；要求区分研究结论、真实行为与游戏推论，并说明申辩为何改变或没有改变名单。
4. `learning[]` 只能引用当次文献 ID 与真实事件编号。初判/终判至少三篇且覆盖三领域，讨论至少两篇。缺失引用、伪造编号、超载或批准未存活玩家都会回退。
5. 每阶段保存查询、命中依据、材料快照、资料库版本/哈希、名单和模型状态。哈希指学术库，**不是上帝提示词**；完整人设仍由独立数据后端维护，不写入提示词原文/哈希快照。

校验只能确认引用与事件存在，不能保证模型解释准确。玩家可展开中文结论、局限及原文复核。未接通模型时明确显示「本地规则裁决 / 阅读提示」，不假装理解自由文本，不因论文自动改变原有规则排序。

真实联调后增加了确定性事实表 `context.facts`：按玩家列出实际捐赠及金额、科技使用次数与回合、实际世界变化、合作双方、洪水和生存记录。它从冻结日志生成，不让模型计算原始次数，不以装备快照推断使用次数，也不把共享补给当作捐赠。仍保留完整人设和全程日志，事实表只是辅助，不是新的排名公式或自然语言事实校验器。

同时修复了旧日志装备数组与当前玩家状态共享引用的问题：新提交事件独立复制，未来装备不会回填到过去记录。对种子 41 的 368 次操作逐步检查旧事件前缀不变。没有自动改写用户已有存档；已存在的错误历史装备快照不能追溯保证正确，事实表优先使用独立的科技事件规避这类污染。
