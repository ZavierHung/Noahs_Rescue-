# 诺亚救援玩家手册

适用：网页版 `0.4.1-local` 的新对局，1—6 人在同一台电脑上轮流操作。角色只影响形象，没有隐藏技能。旧存档的个别卡牌效果不同，请以界面“本版效果”为准。

## 你的目标

洪水会逐步淹没岛屿。你需要活下来，与同伴一起为方舟储备物资，并在最后说明自己的选择。船位有限：上帝结合实际行动、同伴观察和你的陈述，从幸存者中决定登船名单，不能超载。

登船不是唯一评价。游戏还会分别看大家是否共同生存、是否建成足够运力、是否承担环境代价。没登船不等于没有贡献，也不代表品德差。

## 开始一局

1. 本地服务启动后打开 [游戏首页](http://localhost:3000/)。开发者可用 `npm run dev:mock` 启动免费离线模式。
2. 选择玩家、不同角色和出生旗子，点击开始；也可用快速六人开局。
3. 看顶部的当前行动者、洪水提醒和方舟容量。地图高亮显示合法去处，资源图标表示可采集种类。
4. 随时打开“卡牌图鉴”查看全部行动、科技、灾难牌；悬停或键盘聚焦读短效果，点击卡图看大图。

可以切换查看其他玩家的手牌、装备、资源和捐赠，但查看不代表轮到他。操作前点“返回当前行动玩家”。邀约、洪水等会临时指定另一位玩家回应，按界面提示轮流操作。

## 每轮做什么

全局共 8 轮。每轮所有玩家依次完成：

**用牌 → 移动 → 采集 → 上交材料。**

- 用牌：可使用多张持有牌，也可直接进入移动。科技有即时效果或装备效果。
- 移动：基础最多 2 格，也可以不动；滑板鞋额外 +1。尽早向方舟方向靠近，不能从安全处主动走进淹没区。
- 采集：当前位置有可用资源时拿 1 份，每人每轮一次；空地、淹没区和休养中的资源格不能采。无人机可选择有环境代价的增产。
- 上交：选数量放入方舟，任何位置都能上交，也可保留物资并跳过。系统记录实际捐赠。

每步都可跳过，但待处理的灾难、洪水、交换等须先按提示确认。普通手牌最多 5 张，抽牌满手时新牌会进弃牌堆。

抽牌时间：第 1、2、5、6、7、8 轮开始每人 1 张，第 3 轮洪水结算后每人 1 张；第 3、4 轮开始不抽。第 2、4、6 轮另有公共事件，由轮到的代表在两个公开方案中选择，收益与代价会留档。

## 资源留给自己 还是交给方舟

资源有木头、金属、电力、种子。个人库存用于科技成本、交换和应对洪水；个人种子还能在终局自动救生。方舟库存属于共同储备，不能直接取回。

方舟每累计 **17 份任意资源增加 1 个席位**，最多不超过玩家人数和 6 人：17 份 1 席、34 份 2 席、51 份 3 席。洪水扣库可能减少席位；捐过多少会保留记录，但容量只看目前剩余库存。顶部会显示当前载客量与下一席还差多少。

把所有东西捐光可能让自己受伤；只顾留存则可能没有足够船位。两者之间没有每局通用的唯一答案。

## 洪水什么时候来

洪水发生在第 **3、5、7 轮所有玩家行动结束后**。

| 洪水      | 每位玩家需支付                | 方舟消耗          |
| --------- | ----------------------------- | ----------------- |
| 第 3 轮末 | 木头或金属 1 份               | 骰定一种资源 1 份 |
| 第 5 轮末 | 种子 1 + 木头/金属/电力任选 1 | 骰定一种资源 2 份 |
| 第 7 轮末 | 电力 1 + 种子 1 + 任意资源 1  | 骰定一种资源 3 份 |

方舟每次只投一次骰：1/2 木头，3/4 金属，5/6 电力。不足只扣实际库存。最后一次的任选资源可以还是种子或电力，但必须在固定支出后仍有剩余。

洪水从外向内淹没三圈。结算面板会醒目列出方舟已扣、你应缴、储备仓减免和实际支付。按当前玩家依次选资源确认；不足不会产生负数，每少缴 1 份积累 1 点伤势，不是当场出局。

第 8 轮末，仍在淹没区者最后可向内移动最多 1 格。随后个人种子自动每份抵消 1 点伤势，用到伤势归零为止。**必须位于安全格，且救生后伤势不超过 5，才算生存。** 种子不能救回仍留在水中的玩家。

## 两种互动别弄混

**邀约是一起领取，不是交换。** 使用邀约，选距离自己最近的两位同伴之一，再选自己想要的资源。对方接受并选他想要的资源后，双方各新增 1 份，可以不同种，没库存也能用。拒绝不消耗卡，可以再邀约。炼金炉使用后，本轮不能继续邀约。

**互助信标才是交换。** 先部署装备，再在装备区点击交换。双方须同格或相邻一格，且各有 1 份愿意交换的物资；对方接受才成交。发动者每轮成功一次，拒绝不计次数。成交后双方本轮不能用机械爪争夺彼此。按钮灰色时看旁边原因：距离、库存、已使用或尚有待处理事项。

## 科技速查

科技行动牌会展示两张科技，选一张执行；条件不够可放弃，行动牌不会退回。重复装备不会叠加。

| 科技       | 怎么用                                                |
| ---------- | ----------------------------------------------------- |
| 空间戒指   | 自动将手牌上限改为 8，灾难减上限仍生效                |
| 滑板鞋     | 自动让普通移动最多 3 格                               |
| 名刀       | 洪水缴纳后仍受困，提供一次最多 2 格向内移动，然后消耗 |
| 采矿无人机 | 采集时选普通或增产；增产同类 +1、环境 −1              |
| 储备仓     | 自动尽可能少付 1 份洪水物资，面板显示减免             |
| 互助信标   | 主动找同格/相邻玩家，各换 1 份，对方同意才成交        |
| 炼金炉     | 付任意 2 份，得到同种 3 份；本轮之后不能邀约          |
| 共享补给舱 | 公开补给，每人选 1 份；库存少者先选                   |
| 生态驱赶器 | 方舟中心以外的人各选弃 1 资源或合法向外 1 格          |
| 黑潮警报器 | 水边等受影响玩家弃 1 资源；没资源则弃 1 手牌          |
| 快速原型机 | 两张行动牌选 1 入手；满手先弃牌                       |
| 废墟蓝图   | 回收弃牌堆里的 1 张行动牌，不回收装备；满手先弃牌     |
| 回收机械爪 | 从同格/相邻玩家随机拿 1 资源；对方没资源则自己抽 1 牌 |

科技还可能改变共享经济、环境、社会。选择前看“本版效果”和分数变化：个人拿到收益，并不代表大家没有付代价。

## 共同世界与灾难

三属性是全体共用的，不是你的个人分数，也不是越高越好。

| 分数  | 会发生什么                       |
| ----- | -------------------------------- |
| 1—2   | 普通低位与极低位两张灾难同时生效 |
| 3—6   | 普通低位灾难                     |
| 7—13  | 稳定区，无该领域灾难             |
| 14—17 | 普通高位灾难，可能有收益也有成本 |
| 18—19 | 普通高位与极高位两张同时生效     |

灾难会影响装备、手牌上限、采集、资源分配、移动等。触发的卡面和实际效果在界面显示；同一档内变分不会每次重复奖励。环境极低的生态崩坏期间，第 r 轮采过的格子要到第 r+2 轮才恢复，其他人也要等待。生态管制可能让邻近玩家付资源阻止污染科技。

主持/实验模式可手动改分，需填写原因并应用；仅拖滑条不会扣物资。这适合课堂实验，不是普通玩家刷贡献的方式。手动改分会让本局生态目标不再评定。

## 终局怎样决定登船

1. 系统先结算谁存活、船能坐几人，AI 无权修改。
2. 全员依次互评或跳过，包括未存活者。可给同伴 1—5 分、评论和事件证据；不要评价没观察到的行为。人气高不会直接换来船位。
3. 上帝根据行为日志、人设、经济/环境/社会学术材料给出初步名单。
4. 每位幸存者各有一次陈述或放弃机会。可以解释取舍、指出错误，最好引用真实事件。
5. 全部回应后公布最终名单。只能选幸存者，且不超过容量，可以不填满。

离线模式会明确标注“本地规则裁决”：它按已记录的捐赠、合作、争夺和世界影响排序，不理解自由申辩。启用 AI 时也可能误读事实，可以对照事件和资料核查，不能把它的判断当作现实中的道德评价。

六人局可共同争取三项练习目标：至少 5 人生存、建成至少 3 席、在有真实环境行动的前提下不额外透支环境。结果还会展示个人贡献和修复行为，不把所有目标合成一个输赢分数。

## 误操作与存档

“行动修正”可撤回最近 20 步成功操作并重做，需要确认。它是全局历史，可能把另一人的回应或整次洪水一起回退；先看提示，不是只退自己的操作。重做不会重新抽牌。提交第一份终局互评或明确跳过后，行动历史锁定，不能看完评价再悔棋。

游戏自动本地保存，刷新或从存档列表可继续。返回选人不会删除旧局。导出 JSON 包含玩家评论和发言，分享前注意隐私。

复盘时可以问：我为自保保留了什么？谁承担了我的收益背后的成本？起点和运气是否影响了贡献？如果重新协商，我们能否让更多人活下来？
