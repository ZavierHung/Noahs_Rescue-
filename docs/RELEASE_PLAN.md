# Noah’s Rescue：网页地图版发行路线

## 当前交付 · 0.3.0-local

当前是本机多人轮流操作的 Web 原型，不是公网联机服务。小程序暂停开发，完整快照位于 `archive/miniprogram-v0.2`，当前网页使用独立 `expedition` 模块和存档。

- `/`：选人、旗子出生、地图、8 回合行动与终局审判。
- `/lab`：原世界属性、灾难与重复上帝触发的调试台。
- 旧 `/play`、`/mobile` 及小程序共用控制器不在当前运行链路。

## 本轮验收范围

- 10 个角色、1—6 人、正六边形规则层、资源标注和洪水区域。
- 邀约/科技行动卡与 13 种科技的对应效果，资源与捐赠记录。
- 第 3/5/7 回合末洪水、骰点扣库、逐人损失与逃生。
- 全局因果日志、完整人设 + 本地 RAG + M3 接口、终局登舟与申辩归档。
- 并发动作版本校验、非法操作原子拒绝、刷新/服务重建恢复。
- 单元/服务测试、完整八回合浏览器实测、6 人窄屏与批量模拟。
- 文件安全门禁不读取真实密钥和玩家记录；自动测试全部隔离。

牌面与地图使用《资产合集.docx》内嵌原图，不使用 Word 的拉伸尺寸。Sites 的本地开发路径只用于本地实现和预览，未配置托管或发布。

## 明确的本地边界

当前没有远程账号/权限；本地操作者能查看所有玩家。JSON 仅支持单进程，不能启动多个 API 共同写同一存档。初判/申辩有过程内串行控制，但模型请求若在响应前进程崩溃，重新请求可能再次计费；新建对局响应丢失后的跨请求幂等尚未实现。

RAG 仍是本地散列嵌入测试模型，不是高质量语义向量模型。没有真实 M3 调用的自动测试不能证明线上额度或模型可用性。旧灾难卡中的未建模连锁机制只展示，不自行执行。

`npm run release:check` 是本地质量门禁，不是密钥全量审计或公网发行许可。该版本未部署、未推送、未发布小程序。

截图保存在被 Git 忽略的 `test-results/`，临时测试存档会清理，不影响玩家数据。浏览器实测包括真实选角/旗子、移动/采集/捐赠、刷新恢复、全八回合洪水/审判/申辩，以及六人局在 390px 宽度下无横向溢出。真实 MiniMax 账号连通性不在本轮验证范围。
