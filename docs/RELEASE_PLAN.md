## 明确的本地边界

当前没有远程账号/权限；本地操作者能查看所有玩家。JSON 仅支持单进程，不能启动多个 API 共同写同一存档。初判/申辩有过程内串行控制，但模型请求若在响应前进程崩溃，重新请求可能再次计费；新建对局响应丢失后的跨请求幂等尚未实现。

新版登船 RAG 使用 22 份中文学术及教学资料（11 本教材、1 份课程指南和原有 10 份研究/评估等资料），中文关键词/双语术语匹配＋本地散列向量辅助，不是高质量语义模型。初判、每次申辩、终判重新检索并保存来源快照。13 份 PDF 本地归档，8 份网页及 1 份大 PDF 仅外链，样章/讲义不冒充全书。v1.1 真实 M3 曾进行小样本联调，人工抽查仍发现解释精度问题，不能当作 v2.0 验证、可靠性或教育效果证明。另增确定性玩家事实表及历史日志不可变修复。详情见 `ACADEMIC_KNOWLEDGE_REPORT.md`。自动测试不能保证之后的线上额度或模型可用性。12 张灾难已落实；资源保护仍是条件确认，不自动推断线下保护行为。

`npm run release:check` 是本地质量门禁，不是密钥全量审计或公网发行许可。该版本未部署、未推送、未发布小程序。
