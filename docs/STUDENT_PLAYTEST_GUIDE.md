# 六人学生试玩与教育反馈表

适用本地学习版。以下是**后续真人验证方案**，不是已经完成的学生实验；不把机器人通关率称为教学有效率。

## 开始前两分钟

主持人说明：“我们要共同争取生存、积累公共运力，并讨论环境代价。船位有限，但没登船不是品德差；上帝的推理也可以被质疑。”

- 6 人各选角色和不同旗点。旗点路线、资源不等价，第一局记录位置，第二局换位置，不把位置优势解释成能力。
- 只让当前行动者操作。点其他人的头像只是查看；手动调节三属性属于主持实验，不是游戏内技能。
- 解释木头、金属、电力和种子图标；种子留作自救或捐给方舟有取舍。三属性是共享世界，不是个人分。
- 让学生先悬停一张卡，复述“得到什么、付出什么”，再开始。手机点卡图，键盘聚焦也能看文字。

## 游戏中尽量不打断

记录而不纠正每次选择：误点次数、规则求助、被动等待、是否看过效果、是否解释过自己的取舍。只有程序卡住或规则理解完全错误时介入，并记录介入。

公共事件到来时，让指定行动者听取意见后点一项。只要求一句理由，不增加强制长作文；程序记录实际选择及影响，口头理由由主持人另记。随机事件中的因果是游戏约定，不直接当现实政策结论。

## 终局互评与审议

1. 所有人都可互评，包括未存活者。只评价观察过的合作；没有观察到就留空／跳过，不要求每人给所有人打分。
2. 建议评论格式：“我观察到 #事件；对谁产生了什么影响；还有什么背景我不了解。”可以只写评论不打分。
3. 互评不是人气投票。评分不能直接兑换船位，评论要接受真实日志核对；不要把落选者公开贴成“自私”或“差学生”。
4. 上帝初判后，幸存者可以反驳事实、价值权衡或文献适用条件。未存活者的意见通过互评进入审议，不因此复活。
5. 终判不能超过船位。分别讨论共同成果、个人行为和分配决定，不把一个总分当作人的价值。

## 同一道前后情景题

“设备可以多拿 1 份资源，但会降低全员共享的环境。公共船位不足，且有同伴因较远的出生点贡献较少。你会如何行动、如何判断谁登船？说明理由和一个可能反对你的观点。”

主持人对前后回答分别记录：

| 观察项 | 记录方式（不计入游戏船位） |
| --- | --- |
| 是否识别共享代价 | 未提到／只说扣分／解释影响谁与何时发生 |
| 是否理解机会成本 | 未提到／只列收益／比较至少两种可行选择 |
| 是否区分事实和意见 | 把评分当事实／知道需查证／引用实际日志并说明证据局限 |
| 是否考虑机会差异 | 只比较绝对捐赠／提及位置／说明怎样影响判断及反对意见 |
| 能否迁移到现实 | 直接把游戏当定律／提出类比／同时指出模型不成立的前提 |

记录原话后再评，不因是否登船、评分高低或引用文献数量判断学习好坏。小样本的前后变化也不能单独证明是游戏造成的。

## 下一轮开发应依据什么

- 若多名学生误读同一张卡：优先改短描述、条件和卡面，补自动测试。
- 若随机事件一项始终不被选：检查是否真正有代价取舍，不能只增大奖励吸引选择。
- 若重复等待或邀约过多：先统计每人等待及有效决策数，再减少重复确认；不要取消受邀者的同意权。
- 若落选等同“坏人”的理解持续出现：优先改结局和上帝语言，不只增加更多论文。
- 若不同出生点长期差距大：单独校准地图，保留位置、策略和轮序的对照数据，不暗中补偿输家。

分享记录时使用化名，不公开学生姓名、互评分数和敏感评论。当前本地版本无账号鉴权，不适合直接作为公开网络课堂服务。
