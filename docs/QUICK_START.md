# 网页地图版：快速试玩与模拟

当前分支是 `feature/web-hex-map`，版本 `0.3.0-local`；旧小程序文档和代码在 `archive/miniprogram-v0.2`。

## 一分钟开局

1. 在根目录运行 `npm run dev:mock`；首次先执行 `npm ci`、`npm --prefix app ci`。
2. 打开 [localhost:3000](http://localhost:3000/)。
3. 默认已选 3 人；点击玩家标签切换配置，从 10 张角色卡中选人，再点地图旗子选择出生地。
4. 点击“确认角色与旗子 · 开始航程”。同一台电脑依次操作不同玩家。
5. 当前玩家依次出牌、移动、采集、上交。绿色格子表示合法目的地；每个步骤都可跳过。
6. 第 3、5、7 轮所有人行动结束后逐人确认洪水损失；第 8 轮后点击“请上帝审判这段航程”。

`dev:mock` 不使用真实模型。需要已有 M3 配置时用 `npm run dev`；模型只在终局审判/申辩时调用。已有服务占用端口时不要重复启动。

刷新恢复本局；返回选人不会删除历史。“全局航程日志”“方舟捐赠记录”和“初判与申辩留档”可追溯行为。卡面点击放大，Esc 关闭。

## 一条命令模拟

```bash
npm run test:simulation       # 20 局
npm run test:simulation -- 100
npm run test:game
npm run release:check
```

模拟器按真实规则命令运行 1—6 人对局，自动选牌、移动、采集、捐赠和支付洪水成本，最后走本地 RAG 和终局裁决。固定种子可复现，输出局数、操作数、事件数、捐赠次数和结果。它不是访问真实游戏的作弊入口。

浏览器测试另有临时 HTTP 服务和存档目录。所有自动测试均不读取实际密钥、不调用真实 M3、不覆盖真实对局。

完整规则、未明确事项的本地约定和后续修改入口见 [README](../README.md)。
