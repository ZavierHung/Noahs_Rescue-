# 原生微信小程序

微信开发者工具导入本目录。先在仓库根目录运行 `npm run dev:mock`；详细导入、六人本地模拟、架构与验收说明见 [手机端本地开发手册](../docs/MOBILE_LOCAL.md)。

- `pages/index/`：八个业务视图，WXML 原生渲染。
- `shared/client.js`：小程序和 React 模拟器共用的应用控制器。
- `shared/quick-game.js`：独立测试身份，自动安排六人并开局，失败后可继续原局。
- `shared/player-guide.js`：与网页共用的玩法指南、模型数据提示与产品版本。
- `assets/`：本地方舟角色与神谕插画，不请求外部图片域名。
- `config.js`：只配置本地 API 地址，严禁放 API Key。
- `app.wxss`：Demo 的奶油色、深绿、经济/社会/环境三色主题。

本目录不需要安装 npm 依赖，不使用 WebView。小程序平台能力仍需在微信开发工具和真机验收。

点击顶部“一键测试开局”即可自动完成六人准备并进入游戏，再通过测试面板切换角色。“返回手动游戏”恢复原身份，不结束原局。流程和一条命令回归见 [快速试玩说明](../docs/QUICK_START.md)。
